## Gemini SDK 3.0 改变默认接口

**2026-11-06｜正式版本。** Google 的 JavaScript 和 Python SDK 将 Gemini Developer API 的默认版本从 `v1beta` 改为 `v1`。SDK 是替应用封装接口请求的工具包。JavaScript 发行说明列出部分仅在旧版本可用的 `-latest` 模型别名，并将 Node.js 最低版本提高到22。Python 改用 `httpx2` 发送请求，默认信任系统证书。两端的代码执行结果现在可表示为文本或内容数组。 [JavaScript 发行说明](https://github.com/googleapis/js-genai/releases/tag/v3.0.0) · [Python 发行说明](https://github.com/googleapis/python-genai/releases/tag/v3.0.0)

**影响。** 只升级依赖也可能改变请求的目标接口。开发者应关注使用模型别名的任务、自定义证书的部署环境，以及把执行结果固定解析成字符串的代码。已接入该 SDK 的项目适合立即核查这些隐式默认值，升级前在测试环境验证真实请求。

## Kakao 发布多模态决策模型

**2026-11-06｜权重发布公告，性能为厂商自测。** Kanana‑2‑v‑decide 可同时接收文字和图像，返回概率、选项或分数。例如，系统可以用照片和描述判断一条售后请求应交给哪条流程。厂商说明可缓存重复选项的向量表示以减少计算，并公布了 H200 上的延迟结果。公告明确使用 Kanana Open License。 [Kakao 官方公告](https://www.kakaocorp.com/page/detail/12193)

**影响。** 工具路由是在多个工具之间选择下一步动作。把这类高频判断交给专门模型，可以让流程直接消费标准结果，少做一次自然语言解析。实际延迟会受硬件和流量影响，模型分数也需要用项目样本校准。适合加入学习计划：了解低置信度时如何转人工或交由更强模型复核，再考虑试用具体权重。

## Inkling 2 Small 先开放托管使用

**2026-11-05｜官方公告日期，北京时间与窗口起点的关系尚未核实，作为补查项。** Thinking Machines Lab 在 Tinker 开放试用、生成及微调。模型支持图像输入，采用混合专家架构，即每次生成只调用部分参数。厂商公布总参数5940亿、激活约170亿，并计划在外部安全测试完成后按 Apache 2.0 发布完整权重。当前已确认的是托管入口，权重发布仍属计划。 [厂商公告](https://thinkingmachines.ai/news/inkling-2-small/)

**影响。** 对需要图像反馈的开发任务，托管入口可用于小规模验证。若评估目标是自托管，交付条件还包括权重可下载、许可明确和运行资源可测量。继续观察实际发布与独立评估即可。
